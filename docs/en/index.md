# About the Project
Lynway WMS was conceived as a simple warehouse management system featuring bin-location tracking.
It is an open-source project designed for personal use and small businesses.
The primary goal: an easy start, with the flexibility for further fine-tuning.

## Basic Principles
- The system must be ready to use right out of the box; a default warehouse and a default storage zone are created upon initial setup.
- It must support the storage of containers, individual products, or products within containers.
- The "Find, Clone, or Create"* principle: allows for on-the-fly product lookup; if key fields of a selected product are modified, a new clone—inheriting the original's attributes—is created, rather than overwriting the original entry.
