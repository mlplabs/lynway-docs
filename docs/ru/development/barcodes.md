## Протокол QR-кодов (Smart Payload)
Единый формат для генерации этикеток на сервере и парсинга камерой в Android:
* Товар: `wms://itm/{id_or_code}`
* Зона / Ячейка: `wms://cel/{code}`
* Контейнер / Тара (LPN): `wms://cnt/{code}`
* *Поведение Android:* По префиксу сразу понимает тип объекта (не позволит отсканировать товар в поле «Целевая ячейка»). Заводские штрихкоды (EAN-13 и др.) отправляются в API как есть.
