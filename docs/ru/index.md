# О проекте  
Lynway WMS задумывалась как простая складская система учета с адресным хранением. 
Проект с открытым исходным кодом, для персонального использования и малого бизнеса.
Основная цель: простой старт, с возможностью дальнейшей тонкой настройки.

## Базовые принципы
- Система должна уметь работать сразу из коробки, со старта создается базовый склад и базовая зона хранения.
- Возможность хранения как тары, так и отдельно продукции, или продукции в таре
- Принцип "Find, Clone or Create"* — поиск товара на лету; при изменении ключевых полей выбранного товара создается новый клон с атрибутов, а не перезаписывается оригинал.


\* отсутствие огромной иерархии и вложений справочников
